# Fable5 diegetic UI source

Create the declared interface element in the same weathered civic-fantasy material language as
the town: dark ink, charcoal leather, aged paper, muted brass, and restrained amber highlights.
Maintain strong contrast for DOM text placed above it. Nine-slice pieces must have exact stable
corners and repeatable edges; icon sheets must keep equal cell bounds and one visual weight.

Do not bake words, numbers, repository names, evidence claims, or decorative pseudo-text into the
image. No modern glossy mobile styling, neon gradients, watermark, presentation mockup, or scene
background.
