# Fable5 effect source

Create only the declared four-frame pixel-art effect on a fixed grid and common center. Preserve
position and apparent volume across frames. The loop must read in order and return cleanly to its
first frame. Use sparse alpha and restrained brightness so evidence-bearing characters, entrances,
and props remain readable beneath it.

No scene background, labels, UI frame, unrelated particles, camera movement, or change of scale
between frames.
