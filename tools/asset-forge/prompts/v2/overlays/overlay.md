# Fable5 overlay source

Create only the declared transparent overlay at the definition's native size and anchor. Preserve
open negative space so the underlying terrain or building remains legible. State overlays such as
ivy, scaffold, snowcap, and tarp must fit their declared scale class without inventing a different
building. Decorative ground overlays must not imply collision or a change in walkability.

No opaque background, full terrain tile, labels, characters, unrelated props, or presentation
frame. Repeated variants must have visibly different cluster placement and silhouette.
