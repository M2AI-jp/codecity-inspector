# Pre-shipping studio

This division is excluded from the customer package.

- `governance/` owns the single product authority and actual owner decisions.
- `art-department/` owns original custody, demand-driven candidate production,
  measurement, and the approved handoff.
- `quality/` owns tests, browser acceptance, evidence, and independent review.

Studio code may consume shipping public interfaces for verification. Shipping
code never imports studio code. Empty promise-only departments are forbidden.
