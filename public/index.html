CodeCity Inspector — backend

This is the backend status page. The pixel-art town frontend has been removed and is being rebuilt; for now only the read-only inspection backend is running here.

HTTP endpoints (loopback only)

  • GET /api/town — the habitable-town model, habitability report, and validated town layout, as JSON.
  • GET /api/city — the raw repository inspection, as JSON.

Command line

Generate a deterministic town.layout.json artifact without starting the server:

npm run generate:town

The target repository is read as data only; its code is never executed. The server binds to 127.0.0.1 and serves JSON and this page under a strict Content-Security-Policy.
